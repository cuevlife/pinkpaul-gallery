# Pinkpaul — Memory Lane

คลังภาพความทรงจำและสวนดอกไม้สำหรับ Pinkpaul เผยแพร่ผ่าน GitHub Pages โดยไฟล์ภาพและเว็บไซต์เป็นสาธารณะ

## ทดลองในเครื่อง

```sh
python -m http.server 8000
```

เปิด `http://localhost:8000` ผ่านเบราว์เซอร์ เลือกรูปในคลังเพื่อดูภาพเต็ม หรือเปิดสวนดอกไม้เพื่อรดน้ำและปลูกดอกไม้ ความคืบหน้าบันทึกไว้ในเบราว์เซอร์เครื่องนั้น ไม่ซิงก์ข้ามอุปกรณ์และอาจหายเมื่อผู้ใช้ล้างข้อมูลเว็บไซต์

## การจัดการภาพ

ไฟล์ `photo-metadata.json` เป็น JSON array ซึ่งแต่ละรายการมี `path`, `date` และ `dateSource` โดยวันที่ใช้รูปแบบ `YYYY-MM-DDTHH:mm:ss` ตามเวลาที่บันทึกในภาพ ไม่ปรับเขตเวลา ระบุ `null` เมื่อไม่ทราบวันที่ ภาพจะเรียงจากเก่าไปใหม่ และภาพที่ไม่ทราบวันอยู่ท้ายสุด ข้อมูลวันอาจมาจาก EXIF หรือชื่อไฟล์ จึงขึ้นอยู่กับความถูกต้องของกล้องและชื่อไฟล์

วางภาพใน `images/` และเพิ่มรายการใน `photo-metadata.json` โดยไม่ใส่ข้อมูลส่วนตัวที่ไม่ต้องการเผยแพร่ ไฟล์ `images.json` ใช้เป็นรายการสำรองเมื่อ metadata โหลดไม่ได้ ซึ่งจะไม่ทราบวันที่ภาพ
