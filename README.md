# Pinkpaul — Our little moments

เว็บไซต์ static สำหรับวันเกิดและความทรงจำของ Pinkpaul ไม่ต้องติดตั้ง dependency โดยใช้ Google Fonts เมื่อเชื่อมต่ออินเทอร์เน็ต และมีฟอนต์สำรองหากโหลดไม่ได้

## เริ่มใช้งาน

วาง `images.json` ไว้ระดับเดียวกับ `index.html` และใส่ภาพไว้ในโฟลเดอร์ `images` จากนั้นเปิด local server ในโฟลเดอร์โปรเจกต์ เช่น:

```sh
python -m http.server 8000
```

เปิด `http://localhost:8000` ในเบราว์เซอร์ การเปิดไฟล์ HTML โดยตรงด้วย `file://` อาจไม่อนุญาตให้ JavaScript อ่าน manifest ได้

## รูปแบบ images.json

ไฟล์ต้องเป็น JSON array ของ path ภาพภายในเว็บไซต์ โดย path สัมพันธ์กับ `index.html` เช่น:

```json
[
  "images/photo-01.jpg",
  "images/photo-02.jpg"
]
```

ใช้ `[]` เมื่อต้องการอัลบั้มว่าง ระบบจะแจ้งสถานะเมื่อ manifest หรือภาพโหลดไม่ได้ และข้ามภาพที่เสีย ชื่อไฟล์ถูกใช้เป็นคำอธิบายภาพสำหรับเทคโนโลยีช่วยเหลือ จึงควรตั้งชื่อให้สื่อถึงเนื้อหาภาพ

คลิกภาพเพื่อดูขนาดใหญ่ ใช้ปุ่มปิดหรือกด Escape เพื่อกลับไปยังแกลเลอรี
