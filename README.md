# Pinkpaul — Memory Lane

แกลเลอรีสวนสามมิติด้วย Three.js สำหรับ Pinkpaul เผยแพร่ผ่าน GitHub Pages โดยไฟล์ภาพและเว็บไซต์เป็นสาธารณะ มีหน้าคลังภาพ 2D สำรองสำหรับอุปกรณ์ที่เปิด 3D ไม่ได้

## ทดลองในเครื่อง

```sh
python -m http.server 8000
```

เปิด `http://localhost:8000` ผ่านเบราว์เซอร์ที่รองรับ WebGL 2 และเข้าถึง CDN ของ Three.js ได้ ใช้ปุ่มบนจอหรือ WASD/ลูกศรเดิน ลากฉากหรือใช้ IJKL เพื่อมอง และแตะกรอบรูปเพื่อขยาย บนมือถือแนะนำแนวนอน กดถือบัวหรือ F แล้วแตะแปลงเพื่อรดน้ำ หรือเล็งด้วยจุดกลางจอแล้วกด E/ปุ่มรดน้ำ รดสองครั้งเพื่อให้ดอกบาน ความคืบหน้าใช้ข้อมูลชุดเดียวกับสวน 2D ในเบราว์เซอร์เดิม ไม่ซิงก์ข้ามอุปกรณ์และอาจหายเมื่อล้างข้อมูลเว็บไซต์

กด **เปิดไฟกลางคืน** เพื่อสลับบรรยากาศสวน หรือเดินเก็บหัวใจทั้ง 5 ดวงเพื่อปลดล็อกจดหมายวันเกิด แตะหัวใจโดยตรง กด E ตอนอยู่ใกล้ หรือใช้ปุ่ม **เก็บหัวใจใกล้ ๆ** ความคืบหน้าและโหมดแสงจะจำไว้ในเบราว์เซอร์เดิม เอฟเฟกต์เคารพการตั้งค่าลดการเคลื่อนไหวของระบบ

## การจัดการภาพ

ไฟล์ `photo-metadata.json` เป็น JSON array ซึ่งแต่ละรายการมี `path`, `date` และ `dateSource` โดยวันที่ใช้รูปแบบ `YYYY-MM-DDTHH:mm:ss` ตามเวลาที่บันทึกในภาพ ไม่ปรับเขตเวลา ระบุ `null` เมื่อไม่ทราบวันที่ ภาพจะเรียงจากเก่าไปใหม่ และภาพที่ไม่ทราบวันอยู่ท้ายสุด ข้อมูลวันอาจมาจาก EXIF หรือชื่อไฟล์ จึงขึ้นอยู่กับความถูกต้องของกล้องและชื่อไฟล์

วางภาพใน `images/` และเพิ่มรายการใน `photo-metadata.json` โดยไม่ใส่ข้อมูลส่วนตัวที่ไม่ต้องการเผยแพร่ ไฟล์ `images.json` ใช้เป็นรายการสำรองเมื่อ metadata โหลดไม่ได้ ซึ่งจะไม่ทราบวันที่ภาพ
