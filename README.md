# Pinkpaul — Memory Lane

แกลเลอรีสวนสามมิติด้วย Three.js สำหรับ Pinkpaul เผยแพร่ผ่าน GitHub Pages โดยไฟล์ภาพและเว็บไซต์เป็นสาธารณะ มีหน้าคลังภาพ 2D สำรองสำหรับอุปกรณ์ที่เปิด 3D ไม่ได้

## ทดลองในเครื่อง

```sh
python -m http.server 8000
```

เปิด `http://localhost:8000` ผ่านเบราว์เซอร์ที่รองรับ WebGL 2 และเข้าถึง CDN ของ Three.js ได้ ใช้ปุ่มบนจอหรือ WASD/ลูกศรเดิน (อิงตำแหน่งปุ่ม จึงใช้ได้ขณะเปิดแป้นไทย) กดค้างคลิกซ้ายหรือขวาแล้วลากฉาก หรือใช้ IJKL เพื่อมอง และแตะกรอบรูปเพื่อขยาย บนมือถือแนะนำแนวนอน กดถือบัวหรือ F แล้วแตะแปลงเพื่อรดน้ำ หรือเล็งด้วยจุดกลางจอแล้วกด E/ปุ่มรดน้ำ รดสองครั้งเพื่อให้ดอกบาน ความคืบหน้าใช้ข้อมูลชุดเดียวกับสวน 2D ในเบราว์เซอร์เดิม ไม่ซิงก์ข้ามอุปกรณ์และอาจหายเมื่อล้างข้อมูลเว็บไซต์

กด **เปิดไฟกลางคืน** เพื่อสลับบรรยากาศสวน หรือเดินเก็บหัวใจทั้ง 5 ดวงเพื่อปลดล็อกจดหมายวันเกิด แตะหัวใจโดยตรง กด E ตอนอยู่ใกล้ หรือใช้ปุ่ม **เก็บหัวใจใกล้ ๆ** ความคืบหน้าและโหมดแสงจะจำไว้ในเบราว์เซอร์เดิม เอฟเฟกต์เคารพการตั้งค่าลดการเคลื่อนไหวของระบบ

เปิด **สมุดบันทึกสวน** เพื่ออ่านเรื่องราวและเดินทางไปยัง 4 โซนของสวน: เรือนกุหลาบ โรงหนังความทรงจำ โมงยามวิสทีเรีย และงานเลี้ยงริมบัว หัวใจและดอกไม้ที่เก็บไว้ยังอยู่เมื่อสลับโซน

เท็กซ์เจอร์หญ้า หิน ดิน และไม้สร้างจากโค้ดโดยไม่ต้องดาวน์โหลดไฟล์ภาพเพิ่ม ผิวน้ำและสายน้ำใช้ shader ที่ขยับตามเวลาและหยุดเมื่อเปิดการลดการเคลื่อนไหว ใน **โปสต์การ์ด Dudu & Bubu** มี GIF สองภาพจาก Tenor พร้อมปุ่มพักและลิงก์ต้นฉบับ โดยจะโหลด GIF เมื่อเปิดโปสต์การ์ดเท่านั้น

## การจัดการภาพ

กด **ชุดภาพ** ในสวน 3D เพื่อเปลี่ยนชุดที่จัดแสดง (สูงสุด 25 รูปต่อชุด) หรือเปิดคลัง 2D เพื่อกรองตามอัลบั้ม ทั้งสองหน้าโหลดไฟล์ภาพย่อก่อน และขอภาพใหญ่เมื่อเปิดดูเท่านั้น

ไฟล์ `photo-metadata.json` เป็น JSON array รายการละ `path` (ภาพใหญ่), `thumb` (ภาพย่อ), `album`, `date` และ `dateSource` วันมาจาก EXIF หรือชื่อไฟล์ ไม่ปรับเขตเวลา และเก็บ `null` หากหาไม่ได้ ไฟล์ `images.json` เป็นรายการสำรองสำหรับคลัง 2D

หากต้องการนำเข้าคลังที่เลือกไว้แล้ว ให้ติดตั้ง Pillow และรัน `python prepare_gallery.py <โฟลเดอร์ภาพ>` สคริปต์จะไม่แก้ต้นฉบับ สร้างไฟล์ WebP สูงสุด 1280px และภาพย่อ 420px ตัด EXIF ออกจากรูปที่เผยแพร่ และแทนที่รายการภาพของเว็บไซต์ หากต้องการรักษาภาพเดิมบางรูปจากโฟลเดอร์ `images/` ให้ระบุชื่อไฟล์หลัง `--keep-legacy` ด้วย
